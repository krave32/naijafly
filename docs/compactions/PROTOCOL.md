# Compaction Protocol

Write a compaction when:
- A phase is completed
- A meaningful milestone is reached
- The project is being paused/resumed

## Compaction Template
```md
# Compaction: <Phase/Milestone Name>

## Date
YYYY-MM-DD

## State at Compaction
- What was built
- What was verified
- Proof artifacts location

## Next Move
- Exact next task
- Any blockers

## Open Questions
- Unresolved items

## SEC Changes
- What changed in BUILD_CONTEXT, NEXT_STEPS, TASK_BOARD, etc.
```

## Rules
- Record verified state, not speculation
- Preserve the exact next move
- Update phase spec status if completing a phase
- Update SEC files in the same change
