# Definition of Done — Araha

A task or milestone is DONE when:

1. **Code** — implemented and matches the task scope (no scope drift)
2. **Tests** — existing tests pass; new tests added for new behavior
3. **Proof** — verification artifact saved (test output, command trace, screenshot)
4. **Review** — checked with Review Mode: findings documented, no regressions, no scope leakage
5. **Compaction** — milestone state recorded in docs/compactions/
6. **SEC updated** — BUILD_CONTEXT, NEXT_STEPS, TASK_BOARD reflect the new state
